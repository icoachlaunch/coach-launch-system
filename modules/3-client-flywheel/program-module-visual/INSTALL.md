# Program Module Visual — step 2 of 2

Builds the finished, printable pages for your Program Modules from the Module Specs written by
**cl-program-module-specs** (step 1). Run this one after your specs are confirmed.

## Install (once)

In Claude, open **Settings → Capabilities → Skills** (or **Customize → Skills** in the app), choose
**Upload skill**, and upload `cl-program-module-visual.zip` unchanged — the page templates and brand kits
inside are what the build uses. Make sure it shows as enabled.

## Run it

Start a new chat and upload:

- your **Module Specs** (`module-01-….md` … `module-09-….md`, or just the ones you want built)
- your **BRAND KIT block** from your Visual Style Guide (`BRAND KIT: …` and any `OVERRIDES:` line)
- a **headshot** (a square-ish photo of you)

Then say: **"Build my module pages."**

Claude confirms what it has, then builds Module 1 and shows it. Edit anything by hand, or ask for changes.
Say **"next"** for the following module, or **"all"** to build the rest in one go.

## What you get

Nine finished pages on a design canvas you can edit, exported as PDFs for your member pack or course
platform. If your Claude account doesn't have the design canvas, you get the same pages as self-contained
HTML files that open in any browser and print to PDF — plus a list of any missing content still on a page
(a member result for a step, your photo), each naming what's needed.

## Tips

- Want a different look? Say "show it in Ink" (or Crimson, Ember, Sovereign, Voltage, Meadow).
- A wording change belongs in the spec first; Claude will offer to update the spec and then the page, so the
  two never drift apart.
