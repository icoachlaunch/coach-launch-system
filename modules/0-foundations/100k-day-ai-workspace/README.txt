------------------------------------------------------------------------
  HOW TO SET IT UP IN CLAUDE (pick one)
------------------------------------------------------------------------

OPTION A - CLAUDE CODE / COWORK  (recommended - the AI can save files for you)
  1. Unzip this folder somewhere easy to find (e.g. your Documents).
  2. Open Claude and point it at this unzipped folder.
  3. Start a new chat and type exactly this:

     "I just set up my $100K Day AI Workspace. Read the
      PROJECT-INSTRUCTIONS.md file in this folder and walk me
      through the setup."

  Claude reads the brain, checks your Foundations, and starts building
  with you - one step at a time. When a builder finishes, Claude can
  write the file straight into the right folder.

OPTION B - CLAUDE PROJECTS (claude.ai)
  1. Go to claude.ai and create a new Project.
  2. Open PROJECT-INSTRUCTIONS.md in any text editor and copy ALL the text.
  3. In your Project, click "Set project instructions" and paste it in.
  4. Upload every other file from this folder into the Project.
  5. Start a new chat and type exactly this:

     "I just set up my $100K Day AI Workspace. Use the
      PROJECT-INSTRUCTIONS and walk me through the setup."

  Claude will output each finished asset in the chat. Copy it, paste it
  over the matching stub file, and re-upload it to the Project.
