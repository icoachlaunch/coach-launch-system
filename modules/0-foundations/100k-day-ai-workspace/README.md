Every folder has a `README.md`. If you ever wonder where something goes, open the README of the
folder you think it belongs in.

## Where the builders are

The builder prompts — the guided interviews that build each document and asset — are **not** in this
folder. They live in **Coach Launch Academy™**, your Training Portal, where they're kept up to date.
When Claude says it's time to build something, download that builder from the portal, paste it into
the chat, and answer one question at a time. Claude saves the result into the right folder here.

That way your folders never go stale when a builder improves.

## The order you build in

1. **Reference first** (about an hour for all five):
   Business Brand Profile → Visual Style Guide (and install your Brand Kit) → Brand Voice
   → Products & Pricing → Competitive Landscape
2. **Then your Client Engine™**, step by step — Steps 1 to 3 build your offer, 4 to 6 fill the
   room and get paid, 7 to 9 fill the machine. Each step's folder README tells you what it needs
   first.

One rule to remember: **one file per asset.** You update the same file over time — never a "-v2" or
"-FINAL." Claude handles the versioning for you.

## Set it up in Claude (pick one)

### Option A — Claude Code / Cowork (recommended — Claude can save files for you)

1. Unzip this folder somewhere easy to find (your Documents folder is perfect).
2. Open Claude and point it at the unzipped folder.
3. Start a new chat and type exactly this:

   > "I just set up my $100K Day AI Workspace. Read the CLAUDE.md file in this folder and walk me
   > through the setup."

Claude reads the brain, checks your Reference docs, and starts building with you — one step at a
time. When a builder finishes, Claude writes the file straight into the right folder.

### Option B — Claude Projects (claude.ai)

1. Go to claude.ai and create a new Project.
2. Open `CLAUDE.md` in any text editor, copy ALL of it, and paste it in as the Project's instructions.
3. Upload every other file from this folder into the Project.
4. Start a new chat and type exactly this:

   > "I just set up my $100K Day AI Workspace. Use the instructions and walk me through the setup."

Claude outputs each finished document in the chat. You copy it, paste it over the matching file,
and re-upload it to the Project.

## Your Brand Kit — one look, installed once

Your look isn't a list of colours you try to remember. It's a **Brand Kit** — one real file that
every slide, page, ad and post reads from. You pick one of six in your Visual Style Guide, save its
file into `Reference/brand-kit/tokens/`, and never pick a colour again. One Kit installed at a time;
you can change it later, but you replace it — never keep two. `Reference/brand-kit/README.md` has
the how-to.
