# tokens/ — holds exactly ONE file: your Kit

Empty until you choose your Brand Kit in the Visual Style Guide Builder.

When you have, save your Kit's file here, keeping its filename — for example `sovereign.css` — from
https://icoachlaunch.github.io/coach-launch-system/modules/0-foundations/visual-style/brand-kit/tokens/<your-kit>.css

If you ever change Kits, **delete the old file first.** Two token files means two brands, and every
tool you use has to guess which one is true. One Kit installed at a time.
