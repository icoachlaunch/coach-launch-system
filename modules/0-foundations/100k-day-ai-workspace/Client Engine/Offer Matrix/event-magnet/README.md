# Event Magnet™
**Step 3 · Red Diamond Offer™ · Part 3 · Offer Matrix™**

## What goes here
`event-magnet.md` — the free, visual lead magnet built on your hot step — the fuse that fills your event.

One canonical file, updated over time. Bump the version and add a revision-history row when it changes. Never a `-v2` or `-FINAL`.

## How it gets built
Run **the Event Magnet™ Builder** from Coach Launch Academy™ — download it from your Training Portal, paste it into a fresh chat, and answer one question at a time. When it finishes, save the output here as `event-magnet.md`.

## Needs first
Your locked Magic Formula™ (hot step flagged) and $Million Promise™. Money Model recommended, for the CTA.

## Feeds
Your funnel pages (it carries the event's hook and core copy) and slide 1 of your deck.

## Memory
`NOTES.md`, beside the asset — the decisions and why, what was rejected, what's still open, one line per session. Claude reads it before touching this asset and adds to it after every save (it makes the file the first time). Only the status line goes in `CONTEXT.md`; the reasoning stays here.
