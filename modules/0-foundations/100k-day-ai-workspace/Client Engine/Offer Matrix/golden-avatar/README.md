# The Golden Avatar™
**Step 1 · The $Million Story™ · Part 2 · Offer Matrix™**

## What goes here
`golden-avatar.md` — your deep buyer profile(s), each locked at 18/25 with no field under 3.

One canonical file, updated over time. Bump the version and add a revision-history row when it changes. Never a `-v2` or `-FINAL`.

## How it gets built
Run **the Golden Avatar™ Builder** from Coach Launch Academy™ — download it from your Training Portal, paste it into a fresh chat, and answer one question at a time. When it finishes, save the output here as `golden-avatar.md`.

## Memory
`NOTES.md`, beside the asset — the decisions and why, what was rejected, what's still open, one line per session. Claude reads it before touching this asset and adds to it after every save (it makes the file the first time). Only the status line goes in `CONTEXT.md`; the reasoning stays here.
