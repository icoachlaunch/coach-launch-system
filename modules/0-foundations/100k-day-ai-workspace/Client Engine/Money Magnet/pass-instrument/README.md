## What goes here
`pass-instrument.md` — the diagnostic you run in every Paid Audit Strategy Session — nine steps, scored out of 45.

One canonical file, updated over time. Bump the version and add a revision-history row when it changes. Never a `-v2` or `-FINAL`.

**Plus `sessions/`** — one report per live session you run, saved as `sessions/<client-name>-<date>.html`: the client's own document, in YOUR brand, generated at the end of each session by **the PASS™ Session Builder**. Make the `sessions/` folder the first time you run one. These are per-client files, not versions of one asset — one file per session, never overwritten.

## How it gets built
Run **the PASS™ Calibration Builder** from Coach Launch Academy™ — download it from your Training Portal, paste it into a fresh chat, and answer one question at a time. When it finishes, save the output here as `pass-instrument.md`.
