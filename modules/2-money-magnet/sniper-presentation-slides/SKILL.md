**Molds and themes are separate layers, and that separation is the point.** A mold is *structure*:

files; it is twenty molds and six token sets.

That is what lets the user say "rebuild it in Sovereign" and get a completely different-looking deck
in minutes, with every headline still exactly as they approved it.

Everything else — the format, the close, the VIP Hour, the presenter, their system name — is
read from the Script's stamp. You do not ask for what the file already tells you. **The theme is
the one genuine choice the user makes here**, because only they know what their business should

## HOW A SLIDE IS BUILT (the mechanics)

For each row of the plan table:

1. **CLONE the mold.** Find the block whose `data-type` matches the row exactly. Copy its text
   verbatim — it is a complete `<!DOCTYPE html>` document.
2. **SET the surface.** `<html data-surface="L|D|A">` per the row's Surf column.
3. **STAMP the brand.** Replace the `CL-THEME-TOKENS` block with the user's tokens (see
   Auto-Brand below). Identical in every slide. Touch nothing else in the CSS.
4. **FILL the slots**, matching on `data-slot`:
   - `eyebrow` — the beat's own PHASE/ACT label from the Script header. Never a placeholder,
     never invented.
   - `headline` — the beat's SLIDE line. Wrap one pivot word in `<span class="hl">` where the
     mold supports it.
   - `support` — the SLIDE line's second clause, if it has one.
   - `item` — one per list entry. Match the count to the content, respect `data-max`, set
     `data-cells` where the mold takes it, and **delete surplus `item` elements**.
     ⚠️ **Set `data-cells` on the element ONLY.** The same token appears inside the stylesheet's
     selectors (`.grid[data-cells="9"]`), so a blind find-and-replace rewrites the CSS and the grid
     silently renders the wrong column count — the slide still looks plausible, which is why this one
     ships. Anchor the edit to the opening tag. Same care with `data-surface`: it belongs on `<html>`,
     and the CSS matches it unquoted, so only ever change the quoted attribute.
     ⚠️ **Then scan the finished slide for leftovers.** Search it for the mold's own placeholder words
     — `Item`, `Title`, `Name`, `The step`, `Supporting line`, `$0,000`. A stale item still renders,
     and it renders as if it were the client's copy.
   - `presenter` / `brand` — from the stamp.
   - image slots (`photo`, `magnet`, `bg`, `image`) — set a `background-image` only if the user
     supplied one; otherwise **delete the element**.
5. **The SPEAKER SCRIPT never goes on the slide.** It becomes the `notes` on the Viewer entry.
6. **Leave everything else untouched** — layout, animations, the rest of the CSS.

**The fit check, per slide:** count items against `data-max`; check the headline reads at a
glance. Overflow → STOP and show the user (RULE 1). Never trim silently.
