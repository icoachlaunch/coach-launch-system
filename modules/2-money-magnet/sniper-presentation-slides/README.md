# Sniper Presentation™ Slides — Step 4 · Part 3 (The Sniper Close™)

Turn your **Sniper Presentation™ Script** (built in Part 2, The Sniper Close™) into an
on-brand HTML slide deck you present from your own laptop. No PowerPoint, no designer.

## What's in this kit
1. **guide.html** — the companion guide (what it is, the kit, presenter view, setup, layouts, images, tips).
2. **SKILL.md** — the Slide Builder skill (the "brain"). Install at `.claude/skills/sniper-presentation-slides/SKILL.md`, or paste into any chat.
3. **slide-viewer.html** — the Slide Viewer template: a single-file, offline deck player (← → move · F fullscreen · S speaker notes · P pop-out Presenter View · T timer). Ships with an 11-slide sample deck.
4. **images/** — source images used in the sample deck (founder cutout, the generalized 9-step system graphic, etc.).

## How to use
1. Open a chat with the SKILL installed (or pasted) and say: **"Build my slides from my Sniper Presentation™ Script."**
2. It reads your Script + brand, plans the deck, and writes your slides into `slide-viewer.html`.
3. Double-click `slide-viewer.html` to present.
