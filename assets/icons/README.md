# Icons — one per system, one per chapter

Every icon here is from **Streamline Freehand Duotone** (streamlinehq.com, the Coach Launch Icons plan), exported as
SVG at 500 px with exactly two colours: black ink `#101010` and one crimson accent `#db0063`. That is what keeps
them looking like one family. **Never mix in another set or style, never recolour, light backgrounds only.**

## The rule (Matthew, 2026-11-12)

1. **System icons stay.** The 12 system icons below were decided first and always mean their system.
   A chapter that *is* that system uses the system icon.
2. **Every other chapter gets its own icon.** Find it in Streamline's **Freehand Duotone** set, download it as SVG,
   500 px, colours `#101010` + `#db0063`, and save it here named after the chapter's slug (`<slug>.svg`).
3. **Add a row below** and set `icon: '<slug>'` on the chapter in `guidebook/assets/chapters.js`. The Guidebook's
   contents, home cards and chapter header all read the icon from there and from the page's `.hero-art`.
4. **No icon is used twice** for two different things.
